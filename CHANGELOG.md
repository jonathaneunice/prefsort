# Changelog

All notable changes to this project are documented in this file.

## Unreleased

- Switch the project README from reStructuredText to Markdown.

## 0.2.0 - 2026-09-10

- Require Python 3.11 or later.
- Return the matching input values instead of the values given in `preferred`,
  so equal-but-distinct values such as `1.0` and `1` survive reordering intact.
- Modernize packaging, typing, tests, formatting, and continuous integration.
- Ship the full text of the Apache License 2.0.

## 0.1.0 - 2019-06-10

- Simplified the implementation.
- Added tests and the `reverse` parameter.

## 0.0.1 - 2019-06-09

- Initial release.
